=========================================================
 ZOLO'S EXTERNAL - COUNTER-STRIKE 2 
=========================================================

QUICK START:
1. Launch Counter-Strike 2 (set display mode to Borderless Windowed or Windowed).
2. Run "launch.bat" or "esp.exe".
3. Press INSERT to toggle menu.
4. Press HOME for  panic / pause toggle.

DEFAULT CONTROLS:
- INSERT   : Toggle Zolo's External Menu
- HOME     : Panic Button (Instant Master Pause/Resume)
- MOUSE5   : Default Aimbot Key (configurable in Menu -> Aimbot)
- CAPSLOCK : Default Triggerbot Key (configurable in Menu -> Legit & Trigger)

PROFILES INCLUDED:
- config.cfg  : Default Zolo profile (auto-saves on exit)
- legit.cfg   : Zolo Legit (2.5 deg FOV, high smoothing, essential visuals)
- rage.cfg    : Zolo Rage (30 deg FOV, instant smoothing, full ESP + triggerbot)
- visuals.cfg : Zolo Visuals Only (full visuals, aimbot disabled)
